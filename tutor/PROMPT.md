# 작업: The Adventures of Tom Sawyer N장 — 어려운 문장 분석 + 이해 확인 질문 + 읽기 가이드 작성

당신은 한국인 중급 영어 학습자(토익 600~800)를 가르치는 영어 독해 튜터다.
학습자의 약점: (a) 어휘 부족 (b) 긴 문장의 구조 파악이 어려움 — 특히 주어·동사를 못 찾음.
아래 파일들을 읽고, 정확히 두 개의 JSON 파일을 Write 툴로 저장하라. 최종 응답은 `done` 한 줄만.

입력 파일 (`tutor/work/` 폴더):
- `chapter_NN.txt` — 이 장 전문. 각 문장 앞에 `[장.문단.문장]` 번호가 있다.
- `hard_NN.txt`   — 분석해야 할 어려운 문장 목록 (약 22개). `(tags=[...])`는 기계가 찾은 문장구조 유형 번호(아래 표).
- `vocab_NN.txt`  — 이 장의 레벨 2·3 단어 목록 (참고용).

배경: Mark Twain, 1876년 작. 1840년대 미주리주 미시시피 강변 마을 St. Petersburg. 인물 말투는 19세기 미국 남부·서부 아이들 구어(warn't, ain't, gwine, 'bout, kin, reckon)와 흑인 사투리가 섞여 있다. 서술문은 길고 세미콜론·대시가 많으며 풍자적 어조(과장된 격식어)를 쓴다.

## 출력 1: `tutor/analyses_NN.json`  (배열)
hard_NN.txt 의 **모든 문장**에 대해 한 항목씩. 형식:

```json
[
 {
  "id": "1.6.1",
  "en": "<hard_NN.txt 에 있는 문장 원문 그대로. 글자 하나도 바꾸지 말 것>",
  "s": "<주절의 주어 — 문장 안의 연속된 글자열 그대로>",
  "v": "<주절의 동사 — 문장 안의 연속된 글자열 그대로. 조동사 포함 가능 (had been, would have told)>",
  "chunks": [
    {"en": "<의미 단위 1 (원문 그대로)>", "ko": "<이 덩어리의 뜻>", "r": "<역할: 주어 / 동사 / 목적어 / 보어 / 전치사구(장소) / 시간 / 분사구문(~하면서) / 관계절(앞 명사 설명) / 곁말(대시 삽입) / 인용(대사) / 전달동사 / 접속 / 부사 / 대등절 / 부사절(이유) 등 짧게>"},
    ...
  ],
  "ko": "<자연스러운 한국어 전체 번역>",
  "why": "<이 문장이 왜 어려운지, 어떻게 읽어야 하는지 1~2문장. 문법 용어를 쓰면 쉬운 말을 괄호로 덧붙일 것>",
  "st": [3, 12]
 }
]
```

규칙 (매우 중요 — 프로그램이 자동 검증한다):
1. `chunks[].en` 을 순서대로 공백 한 칸으로 이어 붙이면 `en` 과 **정확히 같아야** 한다. 즉 문장을 빠짐없이, 겹침 없이, 순서대로 잘라야 한다. 따옴표·대시·쉼표·세미콜론 같은 문장부호도 어느 한 덩어리에 반드시 포함시킬 것 (덩어리 경계는 보통 쉼표·세미콜론·대시·접속사·전치사 앞).
2. 덩어리는 3~10단어 정도의 '의미 단위(sense group)'. 학습자가 앞에서부터 순서대로 읽어 내려가며(직독직해) 이해할 수 있는 크기. 1단어짜리로 잘게 자르지 말 것.
3. `s`, `v` 는 문장에 실제로 있는 연속 글자열이어야 한다. 세미콜론으로 여러 절이 이어진 문장이면 **첫 번째 절**의 주어·동사를 쓴다. 대사만 있는 문장은 인용문 안의 주절 주어·동사를 쓰고, "said Tom" 구조가 있으면 `s`="Tom", `v`="said". 명령문 등 주어가 없으면 `s`="".
4. `st` 는 아래 18유형 중 이 문장에 실제로 해당하는 번호만 (없으면 빈 배열). tags 는 참고일 뿐 맞는지 판단할 것.
5. `ko` 번역은 뜻이 정확한 것이 최우선. 원문에 없는 내용을 넣지 말 것. 사투리 대사는 자연스러운 한국어 구어로.

문장구조 18유형 번호:
1 인용 뒤 도치 전달동사(said Tom) / 2 사투리·구어 철자 / 3 세미콜론 절 잇기 / 4 대시 삽입·말 끊김 / 5 콜론 / 6 문장 뒤 ~ing(~하면서) / 7 과거분사·형용사로 시작 / 8 부사절이 앞에(When…,) / 9 쉼표+which·whose / 10 as if·as though / 11 도치(부사·부정어 앞) / 12 가정법 / 13 쉼표+for(=because) / 14 and…and…and 나열 / 15 자유간접화법(속생각 의문·감탄) / 16 부가의문문·되묻기 / 17 It was…that / There was / 18 긴 주어(동사가 멀리)

## 출력 2: `tutor/guide_NN.json` (객체)

```json
{
 "chapter": N,
 "intro": "<읽기 전에 알아두면 좋은 배경 2~3문장. 이 장에서 '무슨 일이 일어날지'는 밝히지 말고, 장소·상황·인물 관계·시대 배경 정도만. 스포일러 금지>",
 "characters": [{"name": "Tom Sawyer", "ko": "<이 장 기준 짧은 소개>"}, ...],
 "tips": "<이 장을 읽는 요령 3~4문장. 어떤 부분이 어렵고(긴 서술문? 사투리 대화? 풍자?) 어떻게 접근할지. 구체적으로, 문단 번호를 들어서>",
 "questions": [
   {"q": "<한국어 이해 확인 질문>", "a": "<정답 (근거 문장 번호 [1.x.y] 포함)>", "t": "literal"},
   {"q": "...", "a": "...", "t": "inference"},
   {"q": "...", "a": "...", "t": "vocab"}
 ],
 "predict": "<다음 장을 예측하게 하는 질문 1개 (한국어)>",
 "summary_hint": "<학습자가 이 장을 2~3문장으로 요약할 때 꼭 들어가야 할 핵심 요소 3가지를 짧게 (채점 기준용)>"
}
```
- questions 는 6개: literal(본문에 그대로 나옴) 3개, inference(추론) 2개, vocab(문맥 속 단어 뜻) 1개. 아주 짧은 장(CONCLUSION 등)은 3개만.
- 모든 질문·답은 한국어. 답에는 근거가 되는 문장 번호를 넣을 것.

두 파일 모두 UTF-8, 유효한 JSON. 마크다운 코드펜스 없이 JSON 만 저장할 것.

## 가이드만 쓰는 경우 (analyses 를 만들지 않는 장)
`hard_NN.txt` 는 무시하고 `guide_NN.json` 만 위 형식대로 쓴다.
