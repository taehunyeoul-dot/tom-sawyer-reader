# 작업: NASA 기사 어휘에 한국어 뜻 붙이기

한국인 중급 영어 학습자(토익 600~800)가 NASA 기사를 읽으며 공부합니다.
입력 파일의 단어는 이 학습자가 이미 가진 사전(19세기 소설 어휘 5,649개)에 **없는 단어**들입니다.
대부분 현대 과학·기술·행정 어휘이거나 고유명사입니다.

## 입력

`words_NN.txt` — 한 줄에 `단어<TAB>기사에서의 출현빈도`

## 출력: `done_NN.tsv` (같은 폴더)

입력과 **같은 순서, 같은 줄 수**로, 탭 4칸:

```
단어<TAB>품사<TAB>한국어뜻<TAB>레벨
```

- **품사**: n. / v. / adj. / adv. / prep. / conj. / pron. / int. 중 해당하는 것 (여러 개면 `n., v.`)
  - 고유명사(기관·인명·지명·사업명)는 품사를 `pn.` 으로 한다
- **한국어뜻**: 이 맥락(우주·항공·과학·연구 행정)에서 실제로 쓰이는 뜻 1~3개를 쉼표로. 간결하게.
  - 전문어는 짧은 보충을 괄호로: `totality` → `개기(식) 상태(해가 완전히 가려진 때)`
  - 고유명사는 정체를 밝힌다: `kennedy` → `케네디 우주센터(미국 플로리다의 NASA 발사 기지)`
  - 약어는 원말을 밝힌다: `esa` → `유럽우주국(European Space Agency)`
  - 뜻을 정말 모르겠으면 `?` 로 두지 말고, 철자로 미루어 가장 그럴듯한 뜻에 `(추정)`을 붙인다
- **레벨**: 1 = 중고교 기초 / 2 = 수능·토익 중급 / 3 = 고급·전문어·고유명사

주의
- 한 줄이라도 빠뜨리거나 순서를 바꾸면 안 된다. 입력 단어 철자를 그대로 쓸 것.
- 헤더·설명·마크다운 없이 데이터 줄만.
- 결과는 Write 툴로 저장하고, 최종 응답은 `done <줄수>` 한 줄만.
