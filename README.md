# 톰 소여의 모험 리더 — 읽으면서 배우는 영어

Mark Twain, *The Adventures of Tom Sawyer* (1876) 전문을 **읽으면서 영어 독해력을 키우는 웹 앱**입니다.
파일 하나(`index.html`)로 완결되며, 설치·인터넷 연결 없이 브라우저에서 바로 열립니다.

> ## 👉 **바로 열기: https://taehunyeoul-dot.github.io/tom-sawyer-reader/**
>
> 휴대폰에서 이 주소를 열고 브라우저 메뉴의 **"홈 화면에 추가"** 를 누르면 앱처럼 쓸 수 있습니다.
> PC에서는 `index.html` 을 더블클릭해도 똑같이 동작합니다.

> **이어서 작업하려면** → [HANDOFF.md](HANDOFF.md) 를 먼저 보세요. 현재 상태·남은 일·이미 겪은 함정이 정리돼 있습니다.

만든 이유: 영어 독해력의 약점이 **① 어휘 부족 ② 문장 구조 파악**일 때, 그 두 가지를 소설을 읽는 흐름 안에서 해결하려고 만들었습니다.
어떤 근거로 어떤 기능을 넣었는지는 [docs/독해기법_근거보고서.md](docs/독해기법_근거보고서.md) 에 정리했습니다.

### 핵심 기능 — 문장 구조 가이드

읽기 화면은 **소설책 / 구조분석** 두 가지이고, 상단 고정 막대의 버튼으로 언제든 바꿉니다.

| 화면 | 무엇을 보여주나 |
|---|---|
| **소설책** | 한 줄에 문장 하나, 넓은 줄 간격. 왼쪽 숫자는 문단·문장 번호(확인 질문의 근거 번호와 동일). 단어를 누르면 뜻, **문장을 누르면 튜터 분석·구조 분석**이 열립니다 |
| **구조분석** | 문장을 의미 단위마다 한 줄씩 **번호를 붙여** 쌓습니다. **번호 = 읽는 순서**. 들여쓴 줄(└)은 매달린 꾸밈말, 이름표의 **→숫자**가 **무엇을 꾸미는지** 가리킵니다. 줄을 누르면 그 대상이 켜집니다 |

본문 **모든 문장(5,031개)** 에 자동 구문 분석(spaCy)으로 주절의 주어·동사, 의미 단위 경계와 역할(전치사구/부사절/관계절/분사구문/대등절…), 그리고 **각 덩어리가 무엇에 걸리는지**를 붙였습니다. 여기에 더해 **36장 전부**에서 장마다 가장 어려운 문장 22개 안팎(총 741개)에는 튜터가 쓴 의미 단위별 한국어 뜻과 전체 번역이 들어 있습니다.

표기는 이 소설이 나온 시대(1877년) 미국 교실에서 쓰던 **문장 도해(Reed–Kellogg)** 에서 가져왔습니다.

구조분석에 계속 기대지 말고, 익숙해질수록 **소설책** 화면에서 읽고 막히는 문장만 눌러 보세요.
발판(scaffold)은 걷어내는 것이 목적입니다.
→ 왜 이렇게 설계했는지: [docs/문장구조_가이드_의견.md](docs/문장구조_가이드_의견.md)

## 5. 다시 만들기 / 이어서 늘리기

준비물은 파이썬뿐입니다. 문장 구조 분석에만 spaCy 를 씁니다.

```bash
pip install spacy
python -m spacy download en_core_web_sm
```

```bash
python scripts/01_parse_gutenberg.py    # 원문 → 장·문단·문장
python scripts/02_build_lemmas.py       # 단어 세고 원형으로 묶기
python scripts/03_make_chunks.py        # 뜻풀이 맡길 단어 조각내기
#   ↑ chunks/ 를 클로드에게 맡겨 gloss_raw/*.tsv 로 받는다 (PROMPTS.md)
python scripts/04_merge_vocab.py        # 뜻 + 소설 속 예문 합치기
python scripts/05_find_patterns.py      # 문장구조 18유형 예문 찾기
python scripts/06_parse_syntax.py       # 모든 문장 구문 분석 (spaCy)
python scripts/07_annotate.py           # 장별 단어·커버리지·구조 태그
python scripts/10_find_grammar.py       # 문법 주제 46개의 실제 예문을 본문에서 찾기
#   ↑ tutor/grammar/PROMPT.md 대로 클로드에게 맡겨 tutor/grammar/done_NN.json 저장
python scripts/11_build_grammar.py      # 해설 + 예문 합치기 (원문 대조 검증)
python scripts/08_build_reader.py       # → index.html
```

### 문법 자료는 어떻게 만들었나

시중 문법 교재는 저작권이 있어 내용을 그대로 옮길 수 없습니다. 그래서
**'무엇을 어떤 순서로 배울지'(일반적인 문법 교육 과정)만 참고**하고,

- **설명·공식·읽는 요령·흔한 실수**는 이 프로젝트에서 새로 썼습니다
- **영어 예문은 전부 톰 소여 본문**에서 기계로 찾았습니다 (저작권 만료)
- `11_build_grammar.py` 가 예문이 `book.json` 의 문장과 **글자까지 같은지 자동 검증**합니다
  (지어낸 문장이 섞일 수 없게 하는 장치 — 현재 예문 234개, 경고 0건)

교재의 지어낸 예문 대신 지금 읽고 있는 소설에서 그 문법을 만나므로 학습 효과도 더 좋습니다.

**튜터 분석을 다른 장으로 늘리려면**

```bash
python scripts/09_export_chapter.py 13 14 15   # tutor/work/ 에 입력 파일 생성
#   ↑ tutor/PROMPT.md 대로 클로드에게 맡겨 tutor/analyses_NN.json, guide_NN.json 저장
python scripts/08_build_reader.py
```

`08_build_reader.py` 는 분석 문장이 원문과 글자까지 같은지, 의미 단위를 이어 붙이면 원문이 되는지 자동 검증합니다.

## 5-1. 뉴스로 공부하기 (NASA)

읽기 탭 위쪽 **소설 / 뉴스** 버튼으로 전환합니다. 기사는 **매일 자동으로** 채워집니다.

- 소설과 **똑같이 `읽기 전 → 읽기 → 읽은 후` 3단계**입니다 — 단어 미리보기·예측 → 기사(기사/구조분석) → 정밀 확인·요약
- **모든 문장에 튜터 분석(🔍)과 정밀 확인이 있습니다** — 기사 6건 · **125문장 · 419항목**
  (기사 130문장 중 기자 이름·연락처·링크 안내 5개만 제외)
- 담은 단어 카드는 소설 단어와 **같은 복습 대기열**에 들어가고, 카드 앞면에 **그 기사 문장**이 나옵니다
- 기사마다 NASA 원문 링크가 있습니다

기사는 **짧고 완결된 글**이라 소설과 쓰임새가 다릅니다. 소설은 긴 이야기를 밀고 나가는 훈련,
기사는 하나를 **끝까지 정확하게** 읽어 보는 훈련입니다. 그래서 소설은 장마다 어려운 22문장만
고르지만, 기사는 처음부터 끝까지 전부 확인할 수 있게 했습니다. 기사에서 특히 잘 틀리는 곳은
**수동태(행위자가 문장에 없음)** 와 **긴 명사구·동격**이라 확인 항목도 그쪽에 몰려 있습니다.

> **읽는 동안에는 한국어 뜻이 나오지 않습니다.** 기사 구조분석 화면도 의미 단위와 역할만 보여 줍니다.
> 기사는 모든 문장에 분석이 있어서, 뜻까지 깔면 기사 전체가 번역문이 되어 읽기 훈련이 되지 않습니다.
> 뜻은 **문장을 눌렀을 때**와 **읽은 후 정밀 확인**에서만 나옵니다.

> **새 기사에는 처음엔 튜터 분석이 없습니다.** 매일 도는 자동 수집에는 모델이 없어
> 구조분석·단어 뜻까지만 붙습니다. 튜터 분석은 `scripts/15_news_tutor.py` 로 따로 채웁니다.
> 그 사이에도 읽기·구조분석·단어는 전부 됩니다.

### 왜 NASA인가

- **미국 정부 제작물이라 저작권이 없습니다**(퍼블릭 도메인). 앱에 넣어 공개 배포해도 문제가 없습니다.
- **RSS 피드 안에 본문이 통째로** 들어 있어 기사 페이지를 긁을 필요가 없습니다.
- 매일 여러 건 올라오고 길이가 다양해(200~1,500단어) 그날 컨디션에 맞춰 고를 수 있습니다.
- 한계: 주제가 **우주·항공·과학에 한정**됩니다. 대신 문장 구조는 표준적인 현대 영어라 구조 훈련에는 적합합니다.

> 처음에는 VOA Learning English 를 쓰려 했으나, 확인해 보니 VOA 의 모든 RSS 피드가 2025년 3월에서 멈춰 있고
> 기사 페이지·웨이백 스냅샷 모두 본문이 남아 있지 않았습니다. RFA 도 같은 상태이고, Wikinews 는 폐쇄 중입니다.
> 실제로 본문을 받아 올 수 있으면서 재배포까지 가능한 곳은 NASA 였습니다.

## 5-2. 정밀 확인 — "내가 제대로 읽었나"를 가려내기

읽은 후 화면의 첫 카드입니다. **고르는 문제가 아닙니다.**

1. 영어 문장이 나옵니다
2. **직접 한국어로 옮겨 씁니다** — 손으로 쓰면 부정어·누가·무엇을·언제를 전부 확정해야 해서 얼버무릴 수 없습니다
3. 답이 하나로 정해진 **확인 항목**을 하나씩 열어 내 번역과 대조합니다
4. 마지막에 튜터 번역 전문을 봅니다

확인 항목은 **대충 읽으면 조용히 틀리는 다섯 지점**만 골라 만들었습니다.

| 유형 | 무엇을 잡아내나 |
|---|---|
| 부정 | 부정어를 놓쳐 뜻이 정반대가 된 경우 |
| 주체 | 행동한 사람을 잘못 잡은 경우 |
| 대명사 | he/them 이 가리키는 대상을 잘못 짚은 경우 |
| 수식 | 꾸미는 말을 엉뚱한 데 붙인 경우 |
| 시간 | 시제·시간 순서를 놓친 경우 |

현재 소설 **741문장 / 2,516항목**(36장 전부), 기사 **125문장 / 419항목**(6건 전부·모든 문장). 문장당 2~4개.

> **한계를 분명히 해 둡니다.** 이 기능은 **틀렸다는 신호는 믿을 만하지만, 맞았다는 신호는 완전하지 않습니다.**
> 항목이 짚지 않은 부분은 여전히 검사되지 않고, 자기 대조라는 성격도 남습니다.
> 그래도 "틀렸는데 모르고 넘어가는 것"을 막는 것이 목적이므로, 경보 장치로서는 제 역할을 합니다.
> 확실히 하고 싶은 문장은 번역을 써서 사람(또는 클로드)에게 확인받는 것이 가장 정확합니다.

**구조 연습**(그 아래 카드)은 의미 단위를 섞어 놓고 순서를 맞추는 연습입니다.
영어는 어순·기능어 단서가 강해 **뜻을 몰라도 상당수 맞출 수 있으므로, 어순 감각 훈련이지 이해도 검사가 아닙니다.**
앱에도 그렇게 적어 두었습니다.

## 6. 알려진 한계

- 문장 구조 표시는 **컴퓨터 자동 분석**이라 열에 하나쯤 틀립니다(특히 사투리 대사·긴 삽입절). 앱에도 "자동 분석"이라고 표시해 두었습니다. 튜터 분석(🔍 표시)이 있는 문장은 사람이 검토한 것입니다.
- 단어 뜻풀이 5,629개 중 약 2,657개는 이전 프로젝트(영국 배경 소설)에서 가져온 것입니다. 이 소설과 맞지 않던 58개(reckon, ’bout, grass, stone 등)는 `data/gloss_fix.json` 으로 바로잡았지만, 저빈도 단어에는 아직 어긋나는 것이 남아 있을 수 있습니다. 발견하시면 그 파일에 추가하고 04·07·08번을 다시 돌리면 됩니다.
- 튜터가 직접 쓴 문장 분석(🔍)은 **36장 전부**에 있지만, 장마다 **가장 어려운 22개 안팎**(전체 5,031문장 중 741개, 약 15%)만입니다. 나머지 문장은 자동 구조 가이드가 받쳐 줍니다. 전 문장 번역을 넣지 않는 것은 의도한 설계입니다 — 번역이 다 있으면 영어를 읽는 훈련이 되지 않습니다.
- 13장 이후의 튜터 분석·정밀 확인은 **기계 검증(원문 대조·형식·빠짐)만 전부 통과한 상태**이고, 사람이 학습자 입장에서 풀어 보며 다듬은 것은 1~12장입니다. 억지스러운 항목이 보이면 해당 `tutor/checks/out_NN.json` 을 고치고 `14 merge` → `08` 재빌드하면 됩니다.
- 퀴즈 정답은 자동 분석 기준입니다.
