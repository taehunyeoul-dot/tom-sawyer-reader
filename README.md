# 톰 소여의 모험 리더 — 읽으면서 배우는 영어

Mark Twain, *The Adventures of Tom Sawyer* (1876) 전문을 **읽으면서 영어 독해력을 키우는 웹 앱**입니다.
파일 하나(`index.html`)로 완결되며, 설치·인터넷 연결 없이 브라우저에서 바로 열립니다.

> ## 👉 **바로 열기: https://taehunyeoul-dot.github.io/tom-sawyer-reader/**
>
> 휴대폰에서 이 주소를 열고 브라우저 메뉴의 **"홈 화면에 추가"** 를 누르면 앱처럼 쓸 수 있습니다.
> PC에서는 `index.html` 을 더블클릭해도 똑같이 동작합니다.

만든 이유: 영어 독해력의 약점이 **① 어휘 부족 ② 문장 구조 파악**일 때, 그 두 가지를 소설을 읽는 흐름 안에서 해결하려고 만들었습니다.
어떤 근거로 어떤 기능을 넣었는지는 [docs/독해기법_근거보고서.md](docs/독해기법_근거보고서.md) 에 정리했습니다.

### 핵심 기능 — 문장 구조 가이드

읽기 화면은 **소설책 / 구조분석** 두 가지이고, 상단 고정 막대의 버튼으로 언제든 바꿉니다.

| 화면 | 무엇을 보여주나 |
|---|---|
| **소설책** | 한 줄에 문장 하나, 넓은 줄 간격. 왼쪽 숫자는 문단·문장 번호(확인 질문의 근거 번호와 동일). 단어를 누르면 뜻, **문장을 누르면 튜터 분석·구조 분석**이 열립니다 |
| **구조분석** | 문장을 의미 단위마다 한 줄씩 **번호를 붙여** 쌓습니다. **번호 = 읽는 순서**. 들여쓴 줄(└)은 매달린 꾸밈말, 이름표의 **→숫자**가 **무엇을 꾸미는지** 가리킵니다. 줄을 누르면 그 대상이 켜집니다 |

본문 **모든 문장(5,031개)** 에 자동 구문 분석(spaCy)으로 주절의 주어·동사, 의미 단위 경계와 역할(전치사구/부사절/관계절/분사구문/대등절…), 그리고 **각 덩어리가 무엇에 걸리는지**를 붙였습니다. 1~12장의 어려운 문장 264개에는 튜터가 쓴 의미 단위별 한국어 뜻과 전체 번역이 추가로 들어 있습니다.

표기는 이 소설이 나온 시대(1877년) 미국 교실에서 쓰던 **문장 도해(Reed–Kellogg)** 에서 가져왔습니다.

구조분석에 계속 기대지 말고, 익숙해질수록 **소설책** 화면에서 읽고 막히는 문장만 눌러 보세요.
발판(scaffold)은 걷어내는 것이 목적입니다.
→ 왜 이렇게 설계했는지: [docs/문장구조_가이드_의견.md](docs/문장구조_가이드_의견.md)

## 4. 폴더 구성

```
tom-sawyer-reader/
├ index.html            ← 최종 결과물 (이 파일 하나면 됩니다)
├ manifest.webmanifest  ← 휴대폰 "홈 화면에 추가"용 설정
├ sw.js                 ← 오프라인 캐시(서비스 워커)
├ icon.svg              ← 앱 아이콘
├ reader_template.html  ← 앱의 틀 (디자인·기능은 전부 여기서 고침)
├ scripts/              ← 데이터 만드는 스크립트 (01~09)
├ data/                 ← 만들어진 데이터 (book/vocab/syntax/structures …)
├ chunks/, gloss_raw/   ← 단어 뜻풀이 작업 파일
├ tutor/                ← 튜터(클로드)가 쓴 문장 분석·장 가이드
└ docs/                 ← 근거 보고서·사용법·설계 의견
```

## 5. 다시 만들기 / 이어서 늘리기

준비물은 파이썬뿐입니다. 문장 구조 분석에만 spaCy 를 씁니다.

```bash
pip install spacy
python -m spacy download en_core_web_sm
```

```bash
python scripts/01_parse_gutenberg.py    # 원문 → 장·문단·문장
python scripts/02_build_lemmas.py       # 단어 세고 원형으로 묶기
python scripts/03_make_chunks.py        # 뜻풀이 맡길 단어 조각내기
#   ↑ chunks/ 를 클로드에게 맡겨 gloss_raw/*.tsv 로 받는다 (PROMPTS.md)
python scripts/04_merge_vocab.py        # 뜻 + 소설 속 예문 합치기
python scripts/05_find_patterns.py      # 문장구조 18유형 예문 찾기
python scripts/06_parse_syntax.py       # 모든 문장 구문 분석 (spaCy)
python scripts/07_annotate.py           # 장별 단어·커버리지·구조 태그
python scripts/08_build_reader.py       # → index.html
```

**튜터 분석을 다른 장으로 늘리려면**

```bash
python scripts/09_export_chapter.py 13 14 15   # tutor/work/ 에 입력 파일 생성
#   ↑ tutor/PROMPT.md 대로 클로드에게 맡겨 tutor/analyses_NN.json, guide_NN.json 저장
python scripts/08_build_reader.py
```

`08_build_reader.py` 는 분석 문장이 원문과 글자까지 같은지, 의미 단위를 이어 붙이면 원문이 되는지 자동 검증합니다.

## 6. 알려진 한계

- 문장 구조 표시는 **컴퓨터 자동 분석**이라 열에 하나쯤 틀립니다(특히 사투리 대사·긴 삽입절). 앱에도 "자동 분석"이라고 표시해 두었습니다. 튜터 분석(🔍 표시)이 있는 문장은 사람이 검토한 것입니다.
- 단어 뜻풀이 5,629개 중 약 2,657개는 이전 프로젝트(영국 배경 소설)에서 가져온 것입니다. 이 소설과 맞지 않던 58개(reckon, ’bout, grass, stone 등)는 `data/gloss_fix.json` 으로 바로잡았지만, 저빈도 단어에는 아직 어긋나는 것이 남아 있을 수 있습니다. 발견하시면 그 파일에 추가하고 04·07·08번을 다시 돌리면 됩니다.
- 튜터가 직접 쓴 문장 분석(🔍)은 **1~12장**에만 있습니다(264문장). 13장부터는 자동 구조 가이드가 모든 문장을 받쳐 주며, 필요하면 위 5절의 방법으로 늘릴 수 있습니다.
- 퀴즈 정답은 자동 분석 기준입니다.
