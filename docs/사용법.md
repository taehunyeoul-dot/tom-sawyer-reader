## 1. 처음 한 번만 하는 것

1. **읽기 탭 → 1장 → "내 어휘 수준 점검"**
   레벨 2(수능·토익 중급) 단어 20개 중 **뜻이 바로 안 떠오르는 것만** 체크 → 점검 완료.
   3개 이하면 "레벨 2는 대체로 안다"로 설정되어, 이후 미리보기에는 **레벨 3(고급·옛말·사투리)만** 나옵니다.
   읽기 전 화면 위쪽 버튼으로 언제든 바꿀 수 있습니다.
2. **기록 탭 → 내보내기** 를 가끔 눌러 백업하세요. 기록은 그 브라우저 안에만 있습니다.

## 2. 화면별 기능

### 읽기 탭

왼쪽에 장 목록(휴대폰은 위쪽 드롭다운). 장마다 **읽기 전 → 읽기 → 읽은 후** 3단계입니다.

**1 · 읽기 전**
- 배경·인물 소개, 이 장 읽는 요령, 예측 질문 (36장 전부)
- **단어 미리보기**: 이 장의 레벨 2·3 단어를 장 안 빈도순으로. `98%까지 필요한 것만` / `전부` / `이 장에서 처음 나오는 것` 으로 걸러 볼 수 있습니다.
  - **알아요** = 앞으로 안 물어봄 (커버리지에 반영)
  - **카드** = 단어 복습 목록에 추가
- 다 볼 필요 없습니다. **98% 선까지만** 보고 읽기 시작하세요.

**2 · 읽기**
- 상단 고정 막대의 **소설책 / 구조분석** 버튼으로 언제든 화면을 바꿉니다. 이 막대(탭 → 장 선택 → 단계 → 읽기 화면)는 스크롤해도 늘 화면 위에 붙어 있습니다.

| 화면 | 쓰임새 |
|---|---|
| **소설책** | 한 줄에 문장 하나. 넓은 줄 간격. 왼쪽 회색 숫자 `0·2` = 문단 0의 문장 2 (확인 질문의 근거 번호와 같음) |
| **구조분석** | 의미 단위마다 한 줄씩 **번호**를 붙여 쌓습니다. **번호가 읽는 순서**입니다. 들여쓴 줄(└)은 꾸밈말이고 이름표의 `→3` 은 "3번을 꾸민다"는 뜻. **줄을 누르면 꾸미는 대상이 켜집니다.** 🔍 표시가 붙은 문장은 줄마다 한국어 뜻과 전체 번역이 함께 나옵니다(**36장 전부**) |

- **단어를 누르면** → 뜻·품사·레벨 + [카드 추가] [알아요] [🔊]
- **문장을 누르면** → 튜터 분석·구조 분석 패널 (두 화면 모두에서 열립니다. 휴대폰은 아래에서 올라옵니다)
- 🔍 표시 문장(**36장 전부**, 장마다 22개 안팎 · 총 741문장) = **튜터 분석**. 그 장에서 가장 어려운 문장만 골라 놓은 것이라, 막히면 여기부터 누르면 됩니다
- **도구** 버튼: 글자 크기 · 줄 간격 · 읽는 속도 · 역할 이름 · 새 단어 강조 (한 줄에 하나씩)

**3 · 읽은 후**
- **정밀 확인** (가장 중요) — **36장 전부, 741문장 · 2,516항목.**
  문장을 **먼저 자기 손으로 번역해 쓴 뒤**, 답이 정해진 항목(부정·주체·대명사·수식·시간)과 하나씩 대조합니다.
  고르는 문제가 아니라 쓰는 문제라 찍기·소거법이 통하지 않고, **유추로 넘어간 곳이 드러납니다.**
  - 순서를 꼭 지키세요. **항목을 먼저 열면 효과가 없습니다** — 답을 보고 나면 "나도 그렇게 이해했다"는 느낌이 저절로 생깁니다.
  - 문장당 2~4개, 그 문장에서 정말 헷갈릴 만한 것만 들어 있습니다.

  > **한계를 분명히 해 둡니다.** 이 기능은 **틀렸다는 신호는 믿을 만하지만, 맞았다는 신호는 완전하지 않습니다.**
  > 항목이 짚지 않은 곳에서 잘못 읽었을 수 있습니다. 다 맞혔다고 해서 그 문장을 완전히 이해했다는 뜻은 아닙니다.
- **구조 연습** — 의미 단위를 섞어 놓고 순서 맞추기. 어순 감각 훈련이며 이해도 검사가 아닙니다.
- 기록(시간·WPM·눌러 본 단어), 눌러 본 단어 일괄 카드 추가
- **이해 확인 질문**: 내 답을 먼저 쓰고 → 정답 보기 → 자기 채점 (36장 전부, 총 213문항)
- **주어·동사 찾기 퀴즈**: 5문장, 주어를 누르고 동사를 누르기
- **요약 쓰기**: 2~3문장 (누가·무엇을·그래서 어떻게)
- **완료 표시** → 다음 장으로

### 뉴스 (읽기 탭 → 뉴스)
- 위쪽 **소설 / 뉴스** 버튼으로 전환합니다. **NASA 기사**가 매일 자동으로 채워집니다.
- 목록에서 기사를 고르면 소설과 똑같이 읽습니다 — **기사 / 구조분석** 두 화면, 단어 누르면 뜻, 문장 누르면 주어·동사와 의미 단위 분석.
- 기사 길이가 `짧음 / 보통 / 긺` 으로 표시되니 그날 컨디션에 맞춰 고르세요.
- 담은 단어는 소설 단어와 함께 복습에 나오고, 카드 앞면에 **그 기사 문장**이 보입니다.
- 기사 끝에 NASA 원문 링크가 있습니다.

**기사도 소설과 똑같이 `읽기 전 → 읽기 → 읽은 후` 3단계입니다.**

| 단계 | 하는 일 |
|---|---|
| **읽기 전** | 이 기사의 레벨 2·3 단어 미리보기(알아요 / 카드) · **제목만 보고 무슨 내용일지 한 줄 예측** |
| **읽기** | 기사 본문. **기사 / 구조분석** 두 화면. 여기에는 해석이 없습니다 |
| **읽은 후** | 내 예측 되돌아보기 · **정밀 확인** · 요약 쓰기 · 완료 |

- **기사는 모든 문장에 튜터 분석과 정밀 확인이 있습니다** (125문장·419항목. 기자 이름·연락처·링크 안내만 제외).
  소설은 장마다 어려운 22개만 골라 붙이지만, 기사는 **짧고 완결된 글**이라 처음부터 끝까지 전부 확인할 수 있습니다.
- **읽는 동안에는 한국어 뜻이 나오지 않습니다.** 구조분석 화면도 의미 단위와 역할만 보여 줍니다.
  정답이 눈에 먼저 들어오면 "내가 스스로 읽은 것"인지 알 수 없기 때문입니다.
- 읽다가 정말 막히면 **그 문장을 누르세요.** 그때만 튜터 분석(의미 단위별 뜻)이 열리고,
  거기서 **정밀 확인하기** 버튼으로 바로 넘어갈 수도 있습니다.
- 기사에서 특히 자주 틀리는 곳은 **수동태(누가 한 일인지 안 나옴)** 와 **긴 명사구·동격**입니다. 확인 항목도 그쪽에 몰려 있습니다.

> **쓰는 법**: 소설은 긴 이야기를 밀고 나가는 훈련, 기사는 **하나를 끝까지 정확하게** 읽는 훈련입니다.
> 기사 한 건을 며칠에 걸쳐 하루 2~3문장씩 정밀 확인하면 짧은 글 하나를 완전히 소화하게 됩니다.

> 매일 아침 들어오는 **새 기사에는 처음엔 튜터 분석이 없습니다.** 자동 수집은 구조분석·단어 뜻까지만 붙이고,
> 튜터 분석은 나중에 채워 넣습니다. 그 사이에도 읽기·구조분석·단어는 전부 됩니다.

### 단어 복습 탭
- SM-2 간격 반복(Anki와 같은 방식). 카드 앞면 = 단어 + **소설 속 실제 문장**
- 뜻을 떠올린 뒤 `뜻 보기` → **다시 / 어려움 / 좋음 / 쉬움**
- **철자 쓰기 모드**: 뜻 + 빈칸 문장 → 단어 입력. 더 힘들지만 더 오래 남습니다
- 키보드: <kbd>Space</kbd> 뜻 보기, <kbd>1</kbd>~<kbd>4</kbd> 채점, 철자 모드 <kbd>Enter</kbd>
- `추천 단어 자동 추가` = 빈도 5회 이상 중급·고급 단어 30개
- `카드 목록·관리` = 검색·빼기·알아요 처리·직접 찾아 추가

### 문법 탭
하위 화면 세 가지입니다.

| 화면 | 내용 |
|---|---|
| **문법 주제** | 46가지 주제(시제·동사 뒤·태·조동사·절 잇기·가정법·분사·비교·명사·대명사·부사·전치사·특수 구문). 주제를 누르면 **왜 필요한지 · 공식 · 설명 · 읽을 때 요령 · 흔한 실수**와 **소설 속 실제 예문**이 나옵니다. 예문을 누르면 소설의 그 자리로 이동합니다 |
| **이 소설의 문장 습관** | 트웨인이 이 소설에서 특히 자주 쓰는 18가지 버릇 + 본문에서 찾기 |
| **주어·동사 연습** | 지금 읽는 장에서 5문장, 주어와 동사를 직접 짚기 |

- 주제마다 **연습 — 이 문법이 쓰인 문장 찾기**(4지선다 5문제)가 있습니다. 보기는 전부 소설 실제 문장이고, 오답은 그 문법이 **쓰이지 않은** 문장만 골라 나옵니다.
- **학습 완료로 표시**를 누르면 진도가 올라갑니다(46개 중 몇 개).
- 예문·설명 모두 시중 교재를 옮긴 것이 아니라 새로 쓴 것이며, 영어 문장은 소설 원문과 글자까지 대조해 검증했습니다.

### 기록 탭
완료 장 수, 총 읽기 시간, WPM 그래프, 카드 수, 연속 학습일, 소설 전체 어휘 커버리지, 백업.

## 3. 하루 루틴 (30~40분)

| 순서 | 할 일 | 시간 | 왜 |
|---|---|---|---|
| ① | 단어 복습 오늘 분 | 5~10분 | 간격 반복+인출이 어휘 학습에서 가장 확실 |
| ② | 읽기 전: 새 단어 훑기, 예측 한 줄 | 5분 | 커버리지 98% 원칙, 예측 전략 |
| ③ | 읽기: **멈추지 말고 끝까지** | 15~20분 | 다독의 원칙 — 완벽 이해보다 줄거리 유지 |
| ④ | 읽은 후: 이해 확인 질문 → **정밀 확인 2~3문장** → 주어·동사 퀴즈 → 요약 | 8~12분 | 시험 효과·요약 전략, 그리고 유추로 읽은 곳 찾아내기 |
| ⑤ | (여유) 같은 장 다시 읽기 | 10분 | 반복 읽기로 유창성 |

> **정밀 확인은 그 장의 22문장을 다 할 필요 없습니다.** 하루 2~3문장이면 충분합니다.
> 번역을 손으로 쓰는 일이라 시간이 걸리고, 몰아서 하면 대충 쓰게 됩니다.
> 읽으면서 **"여기 좀 애매한데" 싶었던 문장**을 고르면 가장 효과가 큽니다.

## 4. 구조 가이드 진행표 (중요)

| 시기 | 읽기 화면 | 넘어가는 기준 |
|---|---|---|
| 1~7장 | **구조분석** 위주 | 이야기와 인물에 익숙해지기 |
| 8~15장 | **소설책**, 막히는 문장만 눌러 확인 | 주어·동사 퀴즈 8/10 이상이 2회 연속이면 앞당겨도 좋음 |
| 16장~ | **소설책**만 | 정말 안 풀리는 문장만 |

발판은 걷어내려고 세우는 것입니다. 자세한 이유는 [문장구조_가이드_의견.md](문장구조_가이드_의견.md).

구조분석을 끄고 나서도 **🔍 문장은 계속 눌러 보셔도 됩니다.** 36장 전부에 있고 그 장에서 가장 어려운 문장만 골라 놓은 것이라, 화면 전체를 구조분석으로 되돌리는 것보다 낫습니다. 걷어내야 할 것은 **모든 문장에 자동으로 깔리는 구조 표시**이지, 막히는 문장 하나를 확인하는 일이 아닙니다.

## 5. 1장을 이렇게 읽어 보세요

1. 읽기 전 — 어휘 점검 20단어를 먼저 하고, 미리보기에서 모르는 단어만 카드에 넣기
2. 읽기 — 첫 문단들은 짧은 대사와 폴리 이모의 독백이라 부담이 적습니다. 중간의 긴 서술문(안경 이야기, 담장 이야기)에서 **주어·동사 색 표시부터** 보고 넘어가세요
3. 사투리(`ain't`, `warn't`, `'bout`)는 뜻만 확인하고 계속 — 소리 내어 읽으면 정체가 드러납니다
4. 읽은 후 — 주어·동사 퀴즈 5문장 → 요약 → 완료

## 6. 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| 휴대폰에서 기록이 PC와 다름 | 기록은 기기별로 저장됩니다. 기록 탭 → 내보내기 → 다른 기기에서 불러오기 |
| 읽어주기가 안 됨 | 브라우저에 영어 음성이 없을 수 있습니다(특히 일부 안드로이드). 시스템 설정에서 영어 TTS 음성을 설치하세요 |
| 구조 표시가 틀린 것 같음 | 자동 분석이라 열에 하나쯤 틀립니다. 의심되면 그 감각이 맞습니다 |
| ’bout, ’em 같은 말이 이상하게 풀림 | 사투리 축약형은 따로 사전을 두었습니다. 그래도 이상하면 `data/contractions.json` 에 추가하고 08번 재빌드 |
| 글씨가 작음 | ⚙ 도구 → 글자 크기 |
| 기록을 지우고 싶음 | 기록 탭 → 전부 지우기 |
