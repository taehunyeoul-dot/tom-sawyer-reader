# 톰 소여 리더 — 사용법

여는 방법
- **PC**: `index.html` 더블클릭 (크롬·엣지 권장)
- **휴대폰**: GitHub Pages 주소로 접속 → 브라우저 메뉴 **"홈 화면에 추가"** (설정법은 [README](../README.md) 2절)

## 1. 처음 한 번만 하는 것

1. **읽기 탭 → 1장 → "내 어휘 수준 점검"**
   레벨 2(수능·토익 중급) 단어 20개 중 **뜻이 바로 안 떠오르는 것만** 체크 → 점검 완료.
   3개 이하면 "레벨 2는 대체로 안다"로 설정되어, 이후 미리보기에는 **레벨 3(고급·옛말·사투리)만** 나옵니다.
   읽기 전 화면 위쪽 버튼으로 언제든 바꿀 수 있습니다.
2. **기록 탭 → 내보내기** 를 가끔 눌러 백업하세요. 기록은 그 브라우저 안에만 있습니다.

## 2. 화면별 기능

### 읽기 탭

왼쪽에 장 목록(휴대폰은 위쪽 드롭다운). 장마다 **읽기 전 → 읽기 → 읽은 후** 3단계입니다.

**1 · 읽기 전**
- 배경·인물 소개, 이 장 읽는 요령, 예측 질문 (준비된 장만)
- **단어 미리보기**: 이 장의 레벨 2·3 단어를 장 안 빈도순으로. `98%까지 필요한 것만` / `전부` / `이 장에서 처음 나오는 것` 으로 걸러 볼 수 있습니다.
  - **알아요** = 앞으로 안 물어봄 (커버리지에 반영)
  - **카드** = 단어 복습 목록에 추가
- 다 볼 필요 없습니다. **98% 선까지만** 보고 읽기 시작하세요.

**2 · 읽기**
- **단어를 누르면** → 뜻·품사·레벨·전체 빈도·첫 등장 장 + [카드 추가] [알아요] [🔊]
- **문장의 빈 곳을 누르면** → 문장 패널 (휴대폰은 아래에서 올라옵니다)
  - 주절 주어(초록)·동사(빨강) 표시
  - 의미 단위와 역할 표
  - 🔍 표시 문장(1~12장 각 22개) = **튜터 분석**: 의미 단위별 뜻, "왜 어렵나", 전체 번역
  - `곁말 흐리게` = 대시·괄호·삽입 관계절을 흐리게 해서 뼈대만 보기
- **도구 막대**
  | 항목 | 설명 |
  |---|---|
  | 구조 가이드 | **모든 문장 / 긴 문장만(12단어↑) / 끔** — 익숙해질수록 낮추세요 |
  | 역할 이름 | 경계선 위 작은 글씨(전치사구·부사절…) 표시 여부 |
  | 🔊 읽어주기 | 화면에 보이는 문장부터 순서대로 읽어줍니다 |
  | ⚙ 도구 | 글자 크기·줄간격·구조 태그(번호)·새 단어 강조·읽기 속도 |
  | ⏱ | 읽기 시간 (자동) |
- 맨 아래 **"다 읽었어요"** → 읽기 시간과 WPM(분당 단어 수) 기록

**3 · 읽은 후**
- 기록(시간·WPM·눌러 본 단어), 눌러 본 단어 일괄 카드 추가
- **이해 확인 질문**: 내 답을 먼저 쓰고 → 정답 보기 → 자기 채점 (준비된 장만)
- **주어·동사 찾기 퀴즈**: 5문장, 주어를 누르고 동사를 누르기
- **요약 쓰기**: 2~3문장 (누가·무엇을·그래서 어떻게)
- **완료 표시** → 다음 장으로

### 단어 복습 탭
- SM-2 간격 반복(Anki와 같은 방식). 카드 앞면 = 단어 + **소설 속 실제 문장**
- 뜻을 떠올린 뒤 `뜻 보기` → **다시 / 어려움 / 좋음 / 쉬움**
- **철자 쓰기 모드**: 뜻 + 빈칸 문장 → 단어 입력. 더 힘들지만 더 오래 남습니다
- 키보드: <kbd>Space</kbd> 뜻 보기, <kbd>1</kbd>~<kbd>4</kbd> 채점, 철자 모드 <kbd>Enter</kbd>
- `추천 단어 자동 추가` = 빈도 5회 이상 중급·고급 단어 30개
- `카드 목록·관리` = 검색·빼기·알아요 처리·직접 찾아 추가

### 문장구조 탭
- 이 소설의 18유형 해설 + `본문에서 찾기`(읽는 장 우선으로 실제 문장 12개)
- 맨 위에 **주어·동사 찾기 연습**(지금 읽는 장에서 5문장)

### 기록 탭
완료 장 수, 총 읽기 시간, WPM 그래프, 카드 수, 연속 학습일, 소설 전체 어휘 커버리지, 백업.

## 3. 하루 루틴 (30~40분)

| 순서 | 할 일 | 시간 | 왜 |
|---|---|---|---|
| ① | 단어 복습 오늘 분 | 5~10분 | 간격 반복+인출이 어휘 학습에서 가장 확실 |
| ② | 읽기 전: 새 단어 훑기, 예측 한 줄 | 5분 | 커버리지 98% 원칙, 예측 전략 |
| ③ | 읽기: 타이머 켜고 **멈추지 말고 끝까지** | 15~20분 | 다독의 원칙 — 완벽 이해보다 줄거리 유지 |
| ④ | 읽은 후: 질문 → 주어·동사 퀴즈 → 요약 | 5~8분 | 시험 효과·요약 전략 |
| ⑤ | (여유) 같은 장 다시 읽기 → WPM 비교 | 10분 | 반복 읽기로 유창성 |

## 4. 구조 가이드 진행표 (중요)

| 시기 | 설정 | 넘어가는 기준 |
|---|---|---|
| 1~7장 | 모든 문장 | 이야기와 인물에 익숙해지기 |
| 8~15장 | 긴 문장만 | 주어·동사 퀴즈 8/10 이상이 2회 연속이면 앞당겨도 좋음 |
| 16장~ | 끔 | 막히는 문장만 눌러서 확인 |

발판은 걷어내려고 세우는 것입니다. 자세한 이유는 [문장구조_가이드_의견.md](문장구조_가이드_의견.md).

## 5. 1장을 이렇게 읽어 보세요

1. 읽기 전 — 어휘 점검 20단어를 먼저 하고, 미리보기에서 모르는 단어만 카드에 넣기
2. 읽기 — 첫 문단들은 짧은 대사와 폴리 이모의 독백이라 부담이 적습니다. 중간의 긴 서술문(안경 이야기, 담장 이야기)에서 **주어·동사 색 표시부터** 보고 넘어가세요
3. 사투리(`ain't`, `warn't`, `'bout`)는 뜻만 확인하고 계속 — 소리 내어 읽으면 정체가 드러납니다
4. 읽은 후 — 주어·동사 퀴즈 5문장 → 요약 → 완료

## 6. 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| 휴대폰에서 기록이 PC와 다름 | 기록은 기기별로 저장됩니다. 기록 탭 → 내보내기 → 다른 기기에서 불러오기 |
| 읽어주기가 안 됨 | 브라우저에 영어 음성이 없을 수 있습니다(특히 일부 안드로이드). 시스템 설정에서 영어 TTS 음성을 설치하세요 |
| 구조 표시가 틀린 것 같음 | 자동 분석이라 열에 하나쯤 틀립니다. 의심되면 그 감각이 맞습니다 |
| 글씨가 작음 | ⚙ 도구 → 글자 크기 |
| 기록을 지우고 싶음 | 기록 탭 → 전부 지우기 |
